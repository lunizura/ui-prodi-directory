## Bahasa Indonesia

Pusat basis data terbuka dan direktori web interaktif untuk seluruh program studi, peringkat akreditasi nasional dan internasional, rumpun keilmuan, lokasi kampus, alokasi daya tampung, serta fakultas di **Universitas Indonesia (UI)**, Depok dan Salemba.

Dibuat untuk calon mahasiswa (persiapan seleksi SNBP, SNBT, SIMAK UI, dan PPKB), mahasiswa aktif, akademisi, serta peneliti yang membutuhkan dataset terstruktur mengenai lanskap pendidikan tinggi di universitas peringkat puncak Indonesia.

### Fitur Utama

- **Pencarian Real-Time Cepat:** Cari prodi berdasarkan nama jurusan, kode prodi, maupun nama fakultas secara instan.
- **Antarmuka Dwibahasa Penuh:** Beralih secara instan antara **Bahasa Indonesia** dan **English** dengan sinkronisasi parameter URL (`?lang=id` atau `?lang=en`).
- **Modal Tinjauan Profil Komprehensif (Prodi Overall View):** Klik kartu atau baris tabel untuk melihat profil mendalam:
  - Deskripsi keilmuan resmi (dwibahasa).
  - Fokus kurikulum dan pembelajaran inti.
  - Prospek karir lulusan di industri dan sektor publik.
  - Alokasi kuota daya tampung: Total, SNBP (Prestasi), SNBT (UTBK), dan SIMAK UI (Mandiri).
  - Referensi penetapan UKT Berkeadilan (Kelompok 1 hingga Kelompok 11).
  - Tautan langsung ke portal pendaftaran SIMAK UI dan website resmi program studi.
- **Filter Multi-Kategori Komprehensif:**
  - Jenjang Pendidikan: Sarjana (S1), Sarjana Terapan (D4), Diploma 3 (D3), Magister (S2), dan Doktor (S3).
  - Fakultas & Sekolah Pengelola (17 Unit): FK, FKG, FF, FKM, FIK, FMIPA, FT, FASILKOM, FH, FEB, FPsi, FISIP, FIA, FIB, Program Pendidikan Vokasi, SKSG, dan SIL.
  - Rumpun Keilmuan: Sains & Teknologi (Saintek), Sosial Humaniora (Soshum), Ilmu Kesehatan, dan Multidisiplin.
  - Lokasi Kampus: Kampus UI Depok (Jawa Barat) dan Kampus UI Salemba (Jakarta Pusat).
  - Akreditasi Internasional: Filter khusus prodi yang tersertifikasi oleh lembaga global (AACSB, ABET, IABEE, AUN-QA, RSC, AMBA).
- **Deep Linking & Berbagi Tautan:** Buka profil program studi tertentu langsung melalui parameter URL (`?prodi={id}`) dan salin tautan instan dengan notifikasi toast.
- **Tampilan Fleksibel:** Beralih antara visual kisi kartu (grid view) dan tabel ringkas (table view).
- **Distribusi Data Terbuka (Open Data):** Dataset lengkap tersedia bebas dalam format JSON dan CSV.
