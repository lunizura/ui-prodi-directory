# Security Policy

## Supported Versions

| Version | Supported | Maintenance Level |
|---|---|---|
| 1.0.x (main branch) | Yes | Active security patches and data fixes |
| < 1.0.0 | No | End of Life |

---

## Reporting a Vulnerability

If you identify a security issue, sensitive data leak, or dataset integrity vulnerability:
- Email maintainer: `izuki99999@gmail.com` with subject `[SECURITY] UI Prodi Directory Report`.
- Include reproduction steps and potential impact assessment.
- Do not open public issues for zero-day vulnerabilities.
