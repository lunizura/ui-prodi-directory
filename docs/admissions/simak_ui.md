# Panduan Ujian Seleksi Masuk UI (SIMAK UI)

Seleksi Masuk Universitas Indonesia (SIMAK UI) adalah ujian seleksi mandiri terpadu yang diselenggarakan langsung oleh Universitas Indonesia untuk menjaring calon mahasiswa berprestasi pada berbagai jenjang: Program Vokasi (D3/D4), Sarjana Reguler, Sarjana Kelas Khusus Internasional (KKI), Magister (S2), dan Doktoral (S3).

---

## 1. Jalur Masuk Sarjana Universitas Indonesia

Penerimaan mahasiswa sarjana di UI terbagi ke dalam empat jalur utama:

| Jalur Masuk | Penyelenggara | Kuota Rata-Rata | Kriteria Seleksi |
|---|---|:---:|---|
| **SNBP** | Nasional (BPPP) | 20% - 25% | Prestasi nilai rapor semester 1-5 dan rekam jejak sekolah |
| **SNBT** | Nasional (BPPP) | 30% - 35% | Ujian Tulis Berbasis Komputer (UTBK) nasional |
| **PPKB / Talent Scouting** | Mandiri UI | 10% - 15% | Undangan prestasi nilai rapor untuk sekolah mitra |
| **SIMAK UI** | Mandiri UI | 35% - 40% | Ujian seleksi tertulis daring mandiri berskala nasional |

---

## 2. Struktur Materi Ujian SIMAK UI (Sarjana)

Ujian tulis SIMAK UI dilaksanakan secara daring menggunakan sistem pengawasan kamera komputer (online proctored):

1. **Kemampuan Dasar (KD):** Wajib diikuti oleh seluruh peserta kelompok Saintek maupun Soshum.
   - Matematika Dasar
   - Bahasa Indonesia
   - Bahasa Inggris
2. **Kemampuan IPA (Saintek):**
   - Matematika IPA
   - Fisika
   - Kimia
   - Biologi
3. **Kemampuan IPS (Soshum):**
   - Ekonomi
   - Sejarah
   - Geografi
   - Sosiologi

---

## 3. SIMAK UI Kelas Khusus Internasional (KKI)

Pendaftar program KKI menempuh ujian dalam bahasa Inggris:
- **Basic Mathematics:** Soal kalkulus dasar dan aljabar dalam bahasa Inggris.
- **Critical Reading & Logic:** Penalaran kritis wacana analitis bahasa Inggris.
- **Sertifikasi Kemahiran Bahasa Inggris:** Pendaftar wajib memiliki skor resmi TOEFL ITP (min. 500) / TOEFL iBT (min. 61) / IELTS (min. 5.5).

---

## 4. Mekanisme UKT Berkeadilan UI

Universitas Indonesia menerapkan sistem **Biaya Operasional Pendidikan Berkeadilan (BOP-B)** atau Uang Kuliah Tunggal (UKT) yang berprinsip inklusif:
- Mahasiswa jalur SNBP, SNBT, dan SIMAK UI Reguler dikelompokkan ke dalam 11 kelas UKT sesuai kemampuan finansial penanggung biaya.
- Mahasiswa dari keluarga prasejahtera berhak memperoleh UKT Kelas 1 (Rp 0 - Rp 500.000) hingga pembebasan penuh melalui skema beasiswa KIP-Kuliah.
